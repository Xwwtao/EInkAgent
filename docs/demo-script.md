# 2 分钟演示脚本

顺序按 AGENTS.md P6：能力边界 → 正常问答 → 失败降级 → 评测结果。
回答由真实模型生成，每次措辞不同；建议录 2–3 遍，选最顺的一遍，不剪辑回答内容。

## 录制前准备

```bash
source .venv/bin/activate
python data_import.py
python -m uvicorn eink_agent.api:app
```

- 启动服务的终端要设置 `DEEPSEEK_API_KEY`、`EMBEDDING_API_KEY`、`EMBEDDING_BASE_URL`（见 `.env.example`）。
- 浏览器打开 http://127.0.0.1:8000，点右上角"新对话"，保证偏好栏是空的。
- 另开一个标签页，打开 GitHub 上的 `evals/reports/20261014T125704Z.md`（最后一段要用）。
- 窗口宽度约 1280，字号放大一档，方便看清。

## 备用说法（回答和预期不一样时）

- 第一步模型先追问用途：照实说"信息不够时它会先问"，再补一句"阅读和手写都要"。
- 第三步没有调用知识检索：换问 **电磁笔需要充电吗？**。
- 不要为了画面好看去改提示词或数据；录到的就是当前版本的真实表现。
